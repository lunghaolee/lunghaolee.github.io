# Lung-Hao Lee Academic Homepage

A static, responsive faculty website for GitHub Pages. No build step is required.

## Pages

- `index.html` — homepage with research areas, news, selected publications, and student contact
- `about.html` — biography, education, appointments, and selected honors
- `research.html` — research areas and selected datasets
- `publications.html` — complete publication record with client-side search and filtering
- `teaching.html` — NYCU and NCU teaching
- `activities.html` — academic and professional service

## Deployment

Upload the contents of this folder to the root of the `lunghaolee.github.io` repository and enable GitHub Pages from the main branch.

## Maintenance

- Update Recent News in `index.html`.
- Add new papers to `publications.html`; search/filtering is automatic for items using `publication-item` and `data-kind`.
- Update the footer date when publishing major revisions.
